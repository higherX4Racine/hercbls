# Types of geographic area

A look-up table of one-letter codes for specifying the kind of
geographic area described by a BLS series.

## Usage

``` r
GLOSSARY_OF_AREA_TYPES
```

## Format

An object of class `tibble/tbl_df/tbl/data.frame` with 14 rows and 2
columns

- area_code_type:

  `<chr>` upper-case letters

- areatype_text:

  `<chr>` a short description of the kind of area
