# Read a spreadsheet of Standard Occupational Classification codes

This is an internal function for creating the
[SOC_HIERARCHY](https://higherx4racine.github.io/hercbls/reference/SOC_HIERARCHY.md)
data table.

## Usage

``` r
parse_soc_hierarchy_file(.hierarchy_file)
```

## Arguments

- .hierarchy_file:

  the full path to the spreadsheet

## Value

a data frame of classified occupation types
