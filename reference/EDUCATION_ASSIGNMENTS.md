# Education and training assignments by detailed occupation

A table of educational and training requirements for many different
jobs.

## Usage

``` r
EDUCATION_ASSIGNMENTS
```

## Format

A six-column table.

- Title:

  A verbal description of the occupation type or group

- soc_code:

  The SOC code for this occupation type or group of types

- Education:

  A description of the education required for this job

- Experience:

  A description of the career experience for this job

- Training:

  A description of the on-the-job training for this job
