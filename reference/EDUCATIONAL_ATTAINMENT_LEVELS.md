# Levels of educational attainment, according to the BLS

A table of educational levels with two-digit coedes

## Usage

``` r
EDUCATIONAL_ATTAINMENT_LEVELS
```

## Format

A two-column table.

- credential:

  A verbal description of a level of education.

- bls_id:

  A two-digit integer

## Source

<https://www.bls.gov/emp/tables/education-and-training-by-occupation.htm>
