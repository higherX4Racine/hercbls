# Types of seasonal adjustments

A look-up table of one-letter codes for specifying whether or not a
series' values are seasonally adjusted.

## Usage

``` r
GLOSSARY_OF_SEASONAL_ADJUSTMENTS
```

## Format

An object of class `tibble/tbl_df/tbl/data.frame` with 2 rows and 2
columns

- adjustment_code:

  `<chr>` "U" or "S"

- adjustment_text:

  `<chr>` "Unadjusted" or "Seasonally Adjusted"
